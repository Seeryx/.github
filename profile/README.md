# Seeryx

**Solana-native prediction market.**

Seeryx is a prediction market on Solana where you trade on the outcomes of real-world events: politics, sports, esports, finance, crypto prices and more. Every market has an order book, settles on the Solana blockchain and pays out in USDC.

- **Non-custodial**: funds sit in your own account of the Seeryx program on Solana; only your wallet can withdraw them.
- **No SOL needed**: the exchange pays Solana network fees, so a wallet with only USDC can trade.
- **Open resolution**: event markets resolve through UMA's Optimistic Oracle; crypto rounds on the Binance spot price.
- **Built for builders**: a public REST API and WebSocket for trading bots and apps.

# Seeryx

**Fast, self-custodial prediction market on Solana.**

Seeryx is a prediction market on Solana where you trade on the outcomes of real-world events: politics, sports, esports, finance, crypto prices and stocks. Every market has an order book, settles on the Solana blockchain and pays out in USDC.

- **Fast**: our own central limit order book accepts an order in about 3.5 ms, and every fill settles on Solana.
- **Non-custodial**: funds are native USDC in your own account of the Seeryx program on Solana; only your wallet can withdraw them, and only to itself.
- **No third-party scripts**: the trading site loads only its own code, so no outside vendor can inject anything into the page.
- **No SOL needed**: the exchange pays Solana network fees, so a wallet with only USDC can trade.
- **Open resolution**: event markets resolve through UMA's Optimistic Oracle, brought to Solana via Wormhole; crypto rounds on the Binance spot price; stock rounds on Chainlink data streams.
- **Built for builders**: a public REST API and WebSocket, with official [Python](https://github.com/Seeryx/seeryx-python) and [Rust](https://github.com/Seeryx/seeryx-rust) SDKs.
